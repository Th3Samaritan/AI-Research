BERT: PRE-TRAINING OF DEEP BIDIRECTIONAL TRANSFORMERS · 2 demos live

Delete one mask.
Hide the words instead.

GPT reads left-to-right and predicts the next word — so it can generate. BERT makes two moves: it deletes the causal mask so every token sees both directions at once, and — since next-word prediction is now trivially cheatable — it invents a new exam: hide 15% of the input and reconstruct it. The result set the state of the art on 11 NLP tasks and became the default way to understand text, while GPT remained the way to write it.
