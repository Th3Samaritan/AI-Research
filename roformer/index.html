ROFORMER: ROTARY POSITION EMBEDDING · the position encoding every modern LLM uses

Stop memorising positions.
Rotate them.

GPT-2 adds a learned vector per position — position is a lookup table, and index 1025 is meaningless if you trained with 1024. RoPE instead rotates every query and key by an angle proportional to its position. Rotations compose, so the attention dot product feels only the relative offset m−n — position becomes geometry, needs zero parameters, and works at lengths the model never saw. This is why LLaMA, GPT-NeoX, PaLM, Qwen and DeepSeek all use it.
